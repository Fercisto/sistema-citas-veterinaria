# 🐾 Sistema de Gestión de Citas Veterinarias

Sistema web para la administración de citas en clínicas veterinarias. Permite llevar un control organizado de los pacientes (mascotas), sus propietarios y los síntomas que presentan.

## 🌐 Demo en Vivo

**[Ver Demo](https://spiffy-maamoul-26c511.netlify.app/)**

## ✨ Características

- ✅ **Registro de Citas**: Agrega nuevas citas con información completa del paciente
- ✏️ **Edición de Citas**: Modifica la información de citas existentes
- 🗑️ **Eliminación de Citas**: Elimina citas que ya no son necesarias
- 📋 **Visualización**: Lista organizada de todas las citas registradas
- ✔️ **Validación**: Validación de campos obligatorios en el formulario
- 🔔 **Notificaciones**: Feedback visual para cada acción realizada
- 📱 **Responsive**: Diseño adaptable a diferentes dispositivos

## 🛠️ Tecnologías Utilizadas

- **TypeScript** - Lenguaje de programación tipado
- **HTML5** - Estructura del sitio
- **Tailwind CSS** - Framework de CSS para diseño
- **Vite** - Build tool y dev server
- **Netlify** - Despliegue y hosting

## 📦 Información de Citas

Cada cita incluye:

- **Paciente**: Nombre de la mascota
- **Propietario**: Nombre del dueño
- **Email**: Correo de contacto
- **Fecha**: Fecha de la cita
- **Síntomas**: Descripción del problema de salud

## 💡 Funcionalidades Principales

### Agregar Cita
Complete el formulario con todos los datos requeridos y presione "Registrar Paciente".

### Editar Cita
Haga clic en el botón "Editar" de la cita que desea modificar, actualice la información y guarde los cambios.

### Eliminar Cita
Haga clic en el botón "Eliminar" de la cita que desea remover del sistema.
